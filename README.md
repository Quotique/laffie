Сборка

Для сборки требуется компилятор Rust. Инструкция по установке на оф. сайте https://www.rust-lang.org/tools/install

После установки собрать и запустить систему можно командой

cargo run --release --bin cli -- -c config/cli.json

Рекомендуется использовать имено релизную сборку (флаг --release), так как время работы отличается в разы

Структура каталогов

mcore - содержит решающее ядро системы, которое можно встаивать в различные приложения

mcore/statement - содержит описание термов и образущих структур, утверждений, а так же алгоритм сопоставления с образцом

mcore/rule - содержит описание правил(приемов), а так же алгоритмы выбора правила для текущей логической ситуации

mcore/problem - содержит описание задачи, целевых установок, а так же решающий алгоритм

mcore/predefine - содержит описание некоторых базовых логических символов и их нормализаторов

mcore/utils - содержит вспомогательные структуры и алгоритмы

parser - содержит описание грамматики языка правил за задач, а так же алгоритмы обхода директорий с такими описниями и разбора файлов

view - содержит алгоритмы для форматирования решения, полученного из ядра

database - содержит алгоритмы для работы с базой данных (хранения задач и истории решений)

bin - содержит приложения, использующие ядро

bin/cli - программа с консольным интерфейсом, позволяющая запускать ядро для решения задач из файлов и/или базы данных

bin/tgbot - простой бот для telegram, который позволяет вводить задачи и получать решения

bin/migrate_db - утилита для обновления базы данных, если формат данных обновился


problems - содержит задачи, используемые для тестирования системы

symbols - введенные в систему правила, сгруппированные по привязке к логическим символам
