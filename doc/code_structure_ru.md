
## Структура каталогов

_mcore_ - содержит решающее ядро системы, которое можно встаивать в различные приложения

_mcore/statement_ - содержит описание термов и образущих структур, утверждений, а так же алгоритм сопоставления с образцом

_mcore/rule_ - содержит описание правил(приемов), а так же алгоритмы выбора правила для текущей логической ситуации

_mcore/task_ - содержит описание задачи, целевых установок, а так же решающий алгоритм

_mcore/predefine_ - содержит описание некоторых базовых логических символов и их нормализаторов

_mcore/utils_ - содержит вспомогательные структуры и алгоритмы

_parser_- содержит описание грамматики языка правил за задач, а так же алгоритмы обхода директорий с такими описниями и разбора файлов

_view_- содержит алгоритмы для форматирования решения, полученного из ядра

_database_ - содержит алгоритмы для работы с базой данных (хранения задач и истории решений)

_bin_ - содержит приложения, использующие ядро

_bin/cli_ - программа с консольным интерфейсом, позволяющая запускать ядро для решения задач из файлов и/или базы данных

_bin/tgbot_ - простой бот для telegram, который позволяет вводить задачи и получать решения

_bin/migrate_db_ - утилита для обновления базы данных, если формат данных обновился


**tasks** - содержит задачи, используемые для тестирования системы

**symbols** - введенные в систему правила, сгруппированные по привязке к логическим символам
