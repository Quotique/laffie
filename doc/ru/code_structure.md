
## Структура каталогов

_solver_ - содержит решающее ядро системы, которое можно встраивать в различные приложения

_solver/term_ - содержит описание термов и образующих структур, а так же алгоритм сопоставления с образцом

_solver/rule_ - содержит описание правил (приемов), а так же алгоритмы выбора правила для текущей логической ситуации

_solver/task_ - содержит описание задачи, целевых установок, а так же решающий алгоритм

_solver/term/symbol_ - содержит описание базовых логических символов и их нормализаторов

_utils_ - содержит вспомогательные структуры и алгоритмы

_parser_ - содержит описание грамматики языка правил и задач, а так же алгоритмы обхода директорий с такими описаниями и разбора файлов

_view_ - содержит алгоритмы для форматирования решения, полученного из ядра

_database_ - содержит алгоритмы для работы с базой данных (хранения задач и истории решений)

_bin_ - содержит приложения, использующие ядро

_bin/cli_ - программа с консольным интерфейсом, позволяющая запускать ядро для решения задач из файлов и/или базы данных

_bin/tui_ - программа с терминальным графическим интерфейсом для интерактивной работы с задачами

_bin/tgbot_ - простой бот для telegram, который позволяет вводить задачи и получать решения

_bin/migrate_db_ - утилита для обновления базы данных, если формат данных обновился


**tasks** - содержит задачи, используемые для тестирования системы

**symbols** - введенные в систему правила, сгруппированные по привязке к логическим символам
