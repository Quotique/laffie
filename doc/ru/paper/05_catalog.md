## 5. Каталог примеров

Каталог содержит двенадцать верифицированных параметрических кейсов, на
которых SymPy 1.14.0 систематически теряет или искажает ответ. Карточки
сгруппированы по структуре объекта: одиночные уравнения (C1, C2, C24,
C26, C29, C23), одиночные неравенства (C10, C25, C28), системы
уравнений (C11, C21, C27). Покрытие приёмов из §4 показано сводной
картой в §4.4.

Каждая карточка фиксирует: постановку, поведение чистого SymPy на
свежей версии 1.14.0 с явным указанием механизма потери решения,
гибридный путь с делегированием SymPy в трёх этапах (логический шаг,
делегирование, сборка), правильный кусочный ответ. Источники —
классические задачники (Сканави и др.), GitHub issue tracker SymPy,
StackOverflow, локальная верификация. Полная подборка с воспроизводимыми
SymPy-скриптами приводится в приложении [TODO: cite appendix].

### 5.1. Представительные карточки

Ниже разобраны четыре карточки, иллюстрирующие различные стадии
гибридной схемы и оба механизма делегирования: разбор случаев на
предобработке (C1), ОДЗ-фильтр в постпроцессинге (C29), разбор
случаев внутри процедуры `rref` (C21), двухуровневый разбор случаев
с одновременным вызовом подзадачи и обращением к внешнему
калькулятору (C2). Остальные восемь карточек — в табличной форме в
§5.2.

#### C1 — параметрическое линейное `a · x = a`

*Постановка.* Решить уравнение `a · x = a` относительно `x` с
параметром `a ∈ ℝ`.

*Поведение SymPy.* `solve(Eq(a*x, a), x)` возвращает `[1]` — единственный
корень `x = 1`.

*Механизм потери.* SymPy делит обе части на `a` без проверки `a ≠ 0`
и теряет случай `a = 0`, в котором уравнение становится тождеством
`0 = 0` с произвольным `x`.

*Гибридный путь.*

1. *Логический шаг.* Разбор случаев по обнулению коэффициента при `x`:
   ветви `a = 0` и `a ≠ 0`.
2. *Делегирование SymPy.* В ветви `a ≠ 0` SymPy под допущением о
   ненулевом `a` корректно даёт `x = 1`. В ветви `a = 0` уравнение
   сводится к тождеству, CAS не нужен.
3. *Сборка.* Кусочный ответ: `a = 0` → любое `x`; `a ≠ 0` → `x = 1`.

*Источник.* Классический пример параметрического линейного уравнения;
локальная верификация.

#### C29 — параметрическое иррациональное `√(x − a) + √(x + a) = √(2x)`

*Постановка.* Решить уравнение `√(x − a) + √(x + a) = √(2x)`
относительно `x` с параметром `a ∈ ℝ`.

*Поведение SymPy.* `solve` возвращает `[−a, a]`; `solveset(...,
S.Reals)` — `{−|a|, |a|}`.

*Механизм потери.* ОДЗ исходного уравнения — `x ≥ |a|` (из
неотрицательности всех подкоренных). Возведение в квадрат при
символьном решении даёт формально `x² = a²` и кандидатов `±|a|`.
Корень `x = −|a|` удовлетворяет ОДЗ только при `a = 0`. SymPy не
выполняет постфильтр по ОДЗ.

*Гибридный путь.*

1. *Логический шаг.* Выписывается ОДЗ исходного уравнения: `x ≥ |a|` —
   как фильтр, применяемый к формальным кандидатам после делегирования.
2. *Делегирование SymPy.* SymPy решает уравнение возведением в квадрат
   и возвращает кандидатов `{−|a|, |a|}` — формальная алгебра корректна.
3. *Сборка.* ОДЗ-фильтр применяется к каждому кандидату: `+|a| ≥ |a|`
   проходит всегда, `−|a| ≥ |a|` — только при `a = 0`. Кусочный ответ:
   `a = 0` → `x = 0`; `a ≠ 0` → `x = |a|`.

*Источник.* Сканави, параметрические уравнения с радикалами. *Заметка.*
Эталонная демонстрация ОДЗ-фильтра как постпроцессингового приёма:
формальное решение SymPy переиспользуется без модификации, вся работа
гибрида — на стороне фильтра.

#### C21 — параметрическая `rref` матрицы

*Постановка.* Привести к ступенчатому виду `4 × 4` матрицу с параметрами
`ν, λ`:

```
⎡−3ν     1          0          0⎤
⎢ 3ν   −2ν−1        2          0⎥
⎢ 0     2ν       −ν−λ−2        3⎥
⎣ 0     0         ν+λ         −3⎦
```

*Поведение SymPy.* `A.rref()` возвращает первые три строки единичной
формы с правым столбцом
`[−1/(λν² + ν³), −3/(λν + ν²), −3/(λ + ν), 0]ᵀ` — делит на множители
`ν`, `ν²`, `(λ + ν)` молча.

*Механизм потери.* При `ν = 0` или `λ + ν = 0` выбираемый ведущий
элемент равен нулю, и структура ступенчатой формы меняется (другие
столбцы ведущих элементов).
Публичного API для ответа в форме разбора случаев в `rref` нет.

*Гибридный путь.*

1. *Логический шаг.* Идентификация выражений, на которые гауссова
   процедура хочет делить, — будущих ведущих элементов: `ν` и
   `λ + ν`. Три ветви: общий случай и две вырожденные.
2. *Делегирование SymPy.* В каждой ветви параметры либо имеют
   известное значение, либо ограничены ненулевыми; `A.rref()` под
   этими допущениями возвращает корректную ступенчатую форму без
   скрытых делений.
3. *Сборка.* Кусочный ответ: общий случай (`ν ≠ 0 ∧ λ + ν ≠ 0`) —
   указанная форма; `ν = 0` — столбцы ведущих элементов `(1, 2, 3)` вместо
   `(0, 1, 2)`; `λ + ν = 0` — столбцы ведущих элементов `(0, 1, 3)`.

*Источник.* StackOverflow [TODO: cite SO link]. *Заметка.*
Демонстрирует, что паттерн разбора случаев применим не только к
`solve` / `solveset`, но и к другим алгоритмам CAS, использующим
неявное деление на параметрические выражения.

#### C2 — параметрическое квадратное `(a² − 1) · x² + 2(a − 1) · x + 1 = 0`

*Постановка.* Решить уравнение `(a² − 1) · x² + 2(a − 1) · x + 1 = 0`
относительно `x` с параметром `a ∈ ℝ`.

*Поведение SymPy.* `solve(...)` возвращает пару корней с `(a² − 1)`
в знаменателе и `2 − 2a` под корнем; при `a = 1` обе формулы
вырождаются (`0/0`), при `a = −1` знаменатель обнуляется.

*Механизм потери.* SymPy не разбирает старший коэффициент и не
замечает, что при `a = ±1` тип уравнения меняется (при `a = 1`
одновременно обнуляется и линейный коэффициент `2(a − 1)`). Без
явного разбора случаев по обнулению коэффициентов вырожденные
ветви теряются.

*Гибридный путь* — двухуровневый разбор случаев на универсальном
правиле квадратного уравнения `a · x² + b · x + c == 0`:

```
rule {
    attr level(2), goal(find(x, ..));

    a*x^2 + b*x + c == 0 =>
        answer(
            (a == 0 && lin) ||
            (a != 0 && x in sympy_solve(a*x^2 + b*x + c, x))
        );

    a is known,
    b is known,
    c is known,
    lin == find(x) { b*x + c == 0; b is known; c is known };
}
```

1. *Логический шаг.* Разбор по обнулению старшего коэффициента `a`:
   две ветви, `a == 0` и `a != 0`.
2. *Делегирование.* В ветви `a != 0` правило обращается к
   процедурному символу `sympy_solve(a*x^2 + b*x + c, x)` — обёртке
   над SymPy. В ветви `a == 0` требование
   `lin == find(x) { b*x + c == 0; ... }` запускает подзадачу
   (§3.3) на линейном уравнении с известными `b` и `c`; ответ
   подзадачи, полученный применением соседнего правила линейного
   разбора случаев, связывается с параметром правила `lin`.
3. *Сборка.* Кусочный ответ: при `a = 1` подзадача даёт
   `b = 0, c = 1` → противоречие → `∅`; при `a = −1` подзадача даёт
   `b = −4, c = 1` → `x = 1/4`; иначе квадратные формулы общего
   вида.

Итоговый ответ:
- `a = 1` — `x ∈ ∅`;
- `a = −1` — `x = 1/4`;
- `a ≠ ±1` — `x ∈ {(−a + 1 ± √(2 − 2a)) / (a² − 1)}`.

*Источник.* Сканави, параметрические квадратные уравнения с
вырождением старшего коэффициента. *Заметка.* Карточка
демонстрирует одновременное использование обоих механизмов
делегирования из §3: подзадача (§3.3) обрабатывает вырожденную
ветвь после редукции, внешний CAS (§3.2) — невырожденную; логика
разбора по обнулению старшего коэффициента остаётся на стороне
правила.

### 5.2. Остальные карточки

Остальные восемь карточек каталога приводятся в табличной форме:
постановка, ключевой механизм потери у SymPy, использованные приёмы
из §4. Полные карточки — в [TODO: cite parametric_catalog.md /
appendix].

| Карточка | Постановка | Механизм потери | Приёмы |
|---|---|---|---|
| C24 | `(a² − 4)x = a − 2` | Сокращает `(a − 2)`, теряет обе вырожденные ветви | факторизация + разбор случаев по обнулению |
| C26 | `x⁴ − (a + 1)x² + a = 0` | Не сворачивает `Intersection({±√a, ±1}, Reals)` | факторизация + разбор случаев по знаку |
| C23 | `lim (x e^x − e^{2√(1 + x²)}) / (e^{α x} + x^α)` при `x → +∞` | Не сравнивает порядки роста с символьным `α` | асимпт. редукция + разбор случаев по знаку показателя |
| C10 | `a · x > b` | Не разворачивает знак при `a < 0`, не разбирает `a = 0` | разбор случаев по знаку коэффициента |
| C25 | `a · x² + (a − 1) · x − 1 > 0` | Игнорирует знак направления параболы и относительный порядок корней | факторизация + разбор случаев по знаку и по порядку |
| C28 | При каких `a` неравенство `\|x − 1\| + \|x + 1\| < a` разрешимо | Не работает с `Piecewise` в метавопросе | знак-разбор модулей + редукция метавопроса через экстремум |
| C11 | `{x + y = 1, 2x + 2y = p}` | Возвращает `∅` без анализа rank-дефицита | распознавание rank-дефицита |
| C27 | При каких `a` система `{x + y = a, x² + y² = a}` разрешима в ℝ | Не извлекает условие вещественности из формального решения | редукция метавопроса через формальное решение |
