## Поиск рациональных корней многочлена

### Математическая основа

Теорема о рациональных корнях: если моническый многочлен с целыми коэффициентами
`x^n + ... + d == 0` имеет рациональный корень, то он является делителем свободного
члена `d`.

Для немонического случая `a * x^n + ... + d == 0` рациональные корни имеют вид
`p/q`, где `p` делит `d`, а `q` делит `a`. В реализации поддерживается
монический случай.

### Алгоритм

1. Получить делители свободного члена (включая отрицательные).
2. Подставить каждый кандидат в многочлен.
3. Если подстановка даёт 0 — это корень. Делим многочлен на `(x - u)` и сводим
   задачу к многочлену меньшей степени.

### Правило в Laffie

Обобщённое правило в `symbols/power.sym`:

```
rule {
    attr level(5), goal(find(x, ..));

    F == 0 =>
        (x == u) || (Q == 0);

    is_polynomial(F, x),
    free_term(F, x) == d,
    d != 0,
    u in divisors(d),
    substitute(x == u, F) == 0,
    poly_div(F, x - u) == Q;
}
```

Свободные параметры правила: `F` (связывается из template `F == 0`), `d`, `u`, `Q`
(связываются grounding-ом). Семантика отдельных requirement-ов:

- `is_polynomial(F, x)` — предикат, проверяется после связывания `F` и `x`.
- `free_term(F, x) == d` — `==` с параметром `d` в правой части → связывание
  `d ← -6` (для `F = x^3 - 6x^2 + 11x - 6`). Позиция параметра не важна — `==`
  коммутативный.
- `u in divisors(d)` — генератор: при несвязанном левом аргументе перебирает
  элементы множества.
- `substitute(x == u, F) == 0` — после связывания `u` calculator вычисляет
  подстановку; результат сравнивается с 0 → отбрасывает корни-не-делители.
- `poly_div(F, x - u) == Q` — связывает `Q` частным от деления.

Резолюция `(x == u) || (Q == 0)` после grounding принимает вид
`(x == 1) || (x^2 - 5*x + 6 == 0)` — равенство для найденного корня и редукция
задачи к многочлену меньшей степени.

### Калькуляторы и инфраструктура

| Компонент | Расположение | Назначение |
|-----------|--------------|------------|
| `divisors(n)` | `symbols/divisors.sym` | `set(...)` всех целых делителей `n` |
| `is_polynomial(F, x)` | `symbols/is_polynomial.sym` | проверка многочлена по `x` |
| `free_term(F, x)` | `symbols/free_term.sym` | свободный член многочлена |
| `poly_div(F, divisor)` | `symbols/poly_div.sym` | полиномиальное деление |
| `substitute(x == val, expr)` | `solver/term/symbol/base/substitute.rs` | подстановка переменной |
| `to_sympy` / `from_sympy` | `symbols/py/sympy_convert.py` | общий конвертер Term ↔ SymPy для Python-калькуляторов |
| `Hypothesis::ground()` | `solver/rule/hypothesis.rs` | grounding свободных параметров |

### Конкретизация гипотезы

Свободные параметры `d`, `u`, `Q` доназначаются стандартным механизмом
конкретизации гипотезы (`Hypothesis::ground`): итеративное связывание
по `==` плюс декартово произведение генераторов вида
`param in set(...)`. Подробнее, включая семантику `in` и пошаговый
пример именно для этого правила, см. [hypothesis.md](hypothesis.md).
