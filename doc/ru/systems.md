## Системы уравнений (multi-var find)

### Реализовано

Базовая инфраструктура multi-var find:

- `FindGoal { targets: Vec<TermBuf>, term: TermProps }` — несколько целевых переменных
- `find` — коммутативный символ, `goal(find(x, ..))` в правилах матчит любой find,
  содержащий `x` среди targets
- `check_find_answer` инкрементально связывает targets через `find_bindings`,
  собирает конъюнкцию `&&` когда все bound
- Линейная система `find(x, y)` с `2x - 6 == 0; 3y + 6 == 0` решается

### Известные ограничения

#### Дизъюнктивный ответ для одной из переменных

**Проблема**: `find(x, y)` где `x` имеет дизъюнктивный ответ (`x == -3 || x == 3`)
не решается.

Корень: квадратное уравнение даёт `x in set(-3, 3)`, но этот терм
появляется внутри условной конструкции `36<0 & x∈∅ | 36>=0 & x∈set(-3,3)`,
а не как самостоятельный proven терм. После нормализации появляется `x==-3 || x==3`
— дизъюнкция (`||`), которую `check_find_answer` не матчит (ожидает `==` или `in`).

**Трейс** (задача `-x^2+9==0; 2*y+5==0`):
```
0 -x^2+9=0 None
1 2·y+5=0 None
2 x None
3 y=-2.5 Some(1)          ← y найден
4 0=0 Some(1)
5 36<0&x∈∅|36≥0&x∈set(-3,3) Some(0)  ← x внутри условия
6 x=-3|x=3 Some(5)        ← дизъюнкция, check_find_answer не матчит
NOT SOLVED!
```

**Возможные решения**:
- Научить `check_find_answer` обрабатывать `||` как ответ для одного target
- Извлекать `x in set(...)` из условных конструкций после доказательства условия

**Тестовая задача** закомментирована в `tasks/test/equation.pbl`.
