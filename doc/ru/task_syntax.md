# Синтаксис задач

Задача — это вход в систему, описание того, что требуется сделать:
найти значение неизвестной, доказать утверждение или преобразовать
выражение. Этот документ описывает синтаксис; о понятиях
«целевая установка», «условия», «известное» см.
[terminology.md](terminology.md).

## Структура

Новая задача вводится ключевым словом `task`, за ним идёт целевая
установка, а в фигурных скобках — остальное содержимое:

```
task <целевая_установка> {
    text "Текст задачи для пользователя";
    answer <ожидаемый_ответ>;

    <условие_1>;
    <условие_2>;
    ...
}
```

Все утверждения в фигурных скобках заканчиваются `;`.

## Поля

### Целевая установка

Заголовок задачи между `task` и `{`, обязателен и единственен.

| Форма | Смысл |
|-------|-------|
| `find(x)` | Найти значение `x` через известные термы. |
| `find(x, y, …)` | Многомерный поиск; ответ собирается как конъюнкция `x == … && y == …`. |
| `prove(<утверждение>)` | Доказать утверждение в контексте условий. |
| `transform(<выражение>)` | Преобразовать (упростить) выражение. |

### `text`

Необязательное. Произвольный текст задачи на любом языке. Не
используется системой при решении — выводится пользователю.

```
text "Решите уравнение 2x − 5 = 0";
```

### `answer`

Необязательное. Ожидаемый ответ. Система не использует его при поиске
решения, но сверяет с найденным ответом в конце процедуры. Накопленная
база задач выступает в роли набора интеграционных тестов.

Можно указать несколько `answer`-ов — тогда совпадение хотя бы с одним
считается успехом. Ожидаемый ответ перед сравнением нормализуется.

### Условия

Любое утверждение, не выделенное ключевым словом, считается условием
задачи.

Список условий может быть пустым (задача из одной только цели —
например, `task transform(1 + 2) {}`). В этом случае система начинает
работу, имея только цель.

## Поддерживаемые символы

В термах условий и целевой установки допустимы все функциональные
символы, зарегистрированные в системе. Базовые:

| Группа | Символы |
|--------|---------|
| Сравнение | `<`, `>`, `<=`, `>=`, `==`, `!=` |
| Логические | `&&`, `\|\|`, `!` |
| Арифметические | `+`, `-`, `*`, `/`, `^` |
| Корни | `sqrt(x)` |
| Множества | `set(...)`, `empty_set`, `in` |
| Известность | `is known` |

Этот список расширяется правилами в `symbols/`.

## Примеры

Простейшее линейное уравнение:

```
task find(x) {
    text "Решите уравнение 2x − 5 = 0";

    2*x - 5 == 0;
}
```

Линейное уравнение с раскрытием скобок:

```
task find(x) {
    2*(x + 4) + 3*(x - 5) == 0;
}
```

Линейное уравнение с параметром (`t` объявлено известным, поэтому
может появиться в ответе):

```
task find(x) {
    2*x - 5 + t == 0;
    t is known;
}
```

Квадратное уравнение:

```
task find(x) {
    3*x^2 + 2*x - 5 == 0;
}
```

Дробно-рациональное уравнение:

```
task find(x) {
    1/(x-1) + 2/(x-2) + 3/(x-3) == 6/(x+6);
}
```

Система уравнений (multi-var):

```
task find(x, y) {
    2*x - 6 == 0;
    3*y + 6 == 0;
}
```

Задача на доказательство:

```
task prove(x > 0) {
    x == 2;
}
```

Задача с явным ожидаемым ответом:

```
task find(x) {
    answer x == 1;

    x^3 - 6*x^2 + 11*x - 6 == 0;
}
```

Задача без условий:

```
task transform(1 + 2) {}
```
