## Синтаксис

Новая задача вводится с помощью ключевого слова `task`, далее в фигурных скобках вводится данные задачи.
Ключевое слово `purpose` обозначает целевую установку задачи.

На данный момент существуют три возможные целевые установки:
1. **find(x)** выражение значения переменной _x_ через известные параметры.
2. **proof(&lt;statement&gt;)** доказать истинность утвержение (вывести его из условий задачи).
3. **transform(&lt;statement&gt;)** преобразовать (упростить) выражение.

Целевая установка задачи обязательно должна присутствовать и должна быть единственной.

Необязательное ключевое слово **text** позволяет ввести текст задачи на любом языке. Этот текст никак
не используется системой при решении задачи, он просто выводится пользователю.

Все прочие утвержения считаются условиями задачи.
Список условий не может быть пустым, но может содержать бессмысленные условия, состоящий из констант.
Все утверждения, включая целевую установку, заканчиваются символом **;**

В утвержениях допускаются следующие символы:
_&lt;, &gt;, &lt;=, &gt;=, ==, !=_ - симолы сравнения.
_||, &&_ - логические операции.
_+, -, /, *, ^_ - арифметические операции.
_sqrt(x)_ - квадратный корень.
_set(x, y, z), empty_set_ - множества.

## Примеры задач

Простейшее линейное уравнение:
```
task {
    purpose find(x);
    text "Решите уравнение 2x-5=0";

    2*x-5 == 0;
}
```

```
task {
    purpose find(x);

    2*(x+4) + 3*(x-5) == 0;
}
```

Линейное уравнение с параметром:
```
task {
    purpose find(x);

    2*x-5+t == 0;
    t is known;
}
```

Преобразование логических выражений:
```
task {
    purpose find(x);

    (x^4 - 25*x^2 + 60*x -36 != 0) && ((3600 &lt 0 && x in empty_set) || (3600 &gt= 0 && x in set(1, 4)));
}
```

Квадратное уравнение:
```
task {
    purpose find(x);

    3*x^2+2*x-5 == 0;
}
```

Дробно-рациональное уравнение:
```
task {
    purpose find(x);

    1/(x-1) + 2/(x-2) + 3/(x-3) == 6/(x+6);
}
```

Пример задачи на доказательство:
```
task {
    purpose proof(x &gt 0);

    x == 2;
}
```

Пример задачи с бессмысленным набором условий:
```
task {
    purpose proof(1 &gt 0);

    x == 2;
}
```
