## Терм

Под *термом* понимается корректная формула, состоящая из числовых констант, переменных, параметров
и функциональных символов.

Переменные, параметры и функциональные символы имеют схожий синтаксический вид, но различаются 
своей семантикой.

*Функциональные символы* связанны с сущностями предметной области, например, это могут быть
символы математические операций, физические величины и т. д.
*Параметры* используются правилами в процессе сопоставления терма с шаблоном.
*Переменные* используются для обозначения неизвестных, либо выражений, чьи значения предлагается
считать известными.

## Задача

Система предназначена для решения задач, представимых в следующем виде.

Задача состоит из двух компонентов:

1. *Целевая установка* может быть одной из следующих:

* _find(x)_ - найти x (выразить значение x через известные значения).
* _proof(s)_ - доказать s (вывести терм s из условия задачи).
* _transform(s)_ - преобразовать s к заданному виду (в частности - упростить).

2. *Условия* - список термов, которые можно использовать при решении задачи

Список целевых установок может быть дополнен в дальнейшем.

## Правило

Правила так же представляются в специальном виде.

Каждое правило содержит:

1. _Шаблон(template)_ - терм, содержащий некоторое множество параметров.
2. _Заключение(resolution)_ - терм, содержащий (возможно не все) параметры шаблона.
3. _Требования(requirements)_ - множество термов, описывающие дополнительные условия на параметры
шаблона.

## Применение правила к шаблону

Применение правила r к терму t можно описать следующим алгоритмом:

1. *Унификация* - поиск такого набора значения параметров(термов) m, чтобы после замены их вхождения
в шаблон r получившийся терм r1 совпал с некорым подтермом t1 терма t.
2. *Проверка* - для полученного m проверяются на истинность все требования, если хотя бы одно из
них не выполнено, происходит откат к п. 1 для поиска нового набора m.
3. *Вывод* - в исходном терме t происходит замена подтерма t1 на терм, полученный из заключения
заменой вхождения параметров на значения из m. Полученный результат добавляется к результату,
происходит возвращения к п. 1 для поиска следующего набора.
4. После завершения поиска происходит выход из процедуры применения правила и возврат результата.
