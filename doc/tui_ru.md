# TUI интерфейс

## Основные элементы интерфейса

Интерфейс состоит из трех основных вкладок:

- **F1: Rules** - просмотр доступных правил преобразования
- **F2: Tasks** - список задач и их решение 
- **F3: Tracing** - отслеживание процесса решения задачи 

## Навигация по вкладкам

### Tasks (F2)

**Переключение между панелями:**

- `←` или `h` - фокус на левую панель со списком задач
- `→` или `l` - фокус на правую панель с детальной информацией

**При фокусе на левой панели:**

- `↓`/`j`, `↑`/`k` - перемещение по списку задач
- Текущая задача отмечается символом `>`

**При фокусе на правой панели:**

- `↓`/`j`, `↑`/`k` - скроллинг описания задачи/решения
- Подсвечивается текущая строка

### Tracing (F3)

На вкладке Tracing слева отображается дерево выполнения решения задачи с профилированием. Навигация здесь работает следующим образом:

**Для каждого узла дерева показывается:**

- Для Helper-узлов:
  - Название задачи
  - Количество циклов выполнения
  
- Для Suppose-узлов:
  - Терм предположения
  - Количество циклов
  - Если предположение не доказано - терм отображается зачеркнутым и тусклым

**Управление деревом решения (левая панель):**

- `↓` или `j` - перемещение вниз по дереву
- `↑` или `k` - перемещение вверх по дереву
- `←` или `h` - сворачивание текущего узла дерева
- `→` или `l` - разворачивание текущего узла дерева
- `Enter` или `Space` - переключение состояния узла (свернуть/развернуть)

Текущий узел дерева подсвечивается цветом.

**В правой панели для выбранного узла отображаются детали:**

- Для Helper:
  - Task - название задачи
  - Cycles - количество циклов выполнения

- Для Suppose:
  - Term - терм предположения
  - Rule - использованное правило
  - Cycles - количество циклов выполнения, затраченных на доказательство
  - Requirements - список условий для применения правила

Вся информация о профилировании и времени выполнения отображается в контексте общего количества циклов выполнения задачи.

## Общие действия

- `s` - запустить решение выбранной задачи
- `F1-F3` - переключение вкладок
- `q` - выход из программы

## Запуск программы

```bash
cargo run --release --bin tui -- [options]
```

### Опции запуска

- `-c, --config <PATH>` - конфигурационный файл (по умолчанию cli.yaml)
- `-s, --symbols <PATH>` - директория с правилами
- `-p, --tasks <PATH>` - директория с задачами  
- `-d, --tasks-db <PATH>` - база данных задач (по умолчанию `./db/tasks`)
- `-e, --exec-deadline <NUM>` - лимит циклов выполнения (по умолчанию 100000)
